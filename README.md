# Mamikos — Aplikasi Pencari Kos

Aplikasi pencari kos lengkap dengan 3 role: Tenant, Owner, Admin.

## Tech Stack
- Next.js 14 (App Router)
- Supabase (Auth + Database + Realtime)
- TypeScript + Tailwind CSS
- Lucide Icons

## Demo Accounts
- **Tenant:** tenant@demo.com / demo12345
- **Owner:** owner@demo.com / demo12345
- **Admin:** admin@demo.com / demo12345

Klik tombol akun demo di halaman login untuk auto-create + login.

## Setup Lokal
```bash
npm install
npm run dev
```

## Environment Variables
- `NEXT_PUBLIC_SUPABASE_URL`
- `NEXT_PUBLIC_SUPABASE_ANON_KEY`
